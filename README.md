# smishing_vodafone_analysis
Análisis forense de un SMS fraudulento que suplanta a Vodafone España.  El atacante utiliza un acortador de URL (`goo.su/-9Vodafone`) para redirigir  a una página clonada de Vodafone que roba el número de teléfono de la víctima  para realizar **SIM Swapping** e interceptar códigos 2FA.
